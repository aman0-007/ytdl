# ⚡ RAW DOWNLOADER

**NO BLOAT. NO ADS. JUST THE FILE.**

RAW DOWNLOADER is a high-contrast, Neo-Brutalist web tool designed for users who want to snatch media from the web without the typical "downloader site" experience—meaning zero pop-ups, zero trackers, and zero nonsense.

---

## 🎨 THE VIBE
Built with **Neo-Brutalism** principles:
*   **High Contrast:** Harsh yellows and aggressive reds.
*   **Thick Outlines:** 4px solid black borders on everything.
*   **Hard Shadows:** No blur, just solid offsets.
*   **Typography:** Bold, chunky 'Space Grotesk' for that raw aesthetic.

## 🚀 FEATURES
*   **Universal Snatching:** Supports YouTube, TikTok, Instagram, SoundCloud, and more.
*   **Quality Control:** Select from 360p up to 4K/Max quality.
*   **Audio Extraction:** One-click MP3 conversion.
*   **Serverless Architecture:** Powered by Vercel Functions to bypass CORS and ensure privacy.
*   **Responsive:** Works like a tank on mobile and desktop.

## 🛠️ TECH STACK
*   **Frontend:** Vanilla HTML5, CSS3 (Custom Variables), and JavaScript (ES6+).
*   **Backend:** Vercel Serverless Functions (Node.js).
*   **API Engine:** Powered by the open-source Cobalt API.
